# projet-agence-freelance

Template simple pour une agence freelance — site statique avec page d'accueil, sections services, portfolio, et contact.

## Structure

- index.html: page d'accueil
- styles.css: styles de base

## Utilisation

1. Ouvrir `index.html` dans un navigateur pour voir le site localement.
2. Pour déployer: vous pouvez activer GitHub Pages sur la branche `main` (Settings → Pages) ou héberger via Netlify / Vercel.

## Personnalisation

- Remplacez les textes et les projets du portfolio par vos contenus.
- Pour un formulaire fonctionnel, reliez le formulaire à un back-end ou utilisez un service comme Formspree, Netlify Forms, ou Zapier.
